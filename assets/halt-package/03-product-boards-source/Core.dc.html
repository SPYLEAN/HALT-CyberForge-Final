07 — HALT CORE · 3D OBJECT DEFINITION

The mark, given depth, not decoration

The Core is the identity as a physical object: the same H extruded into thin layers, one per verified step. It is the single 3D form in the product and it carries state, not ornament.

FormExact mark outline, extruded 0.8x. No bevel, no rounding, no added geometry. The node's hole stays open through every layer.
Build22 flat layers at 0.16x pitch. Each layer stands for one verified constraint, so depth reads as proof depth. Back layers step down in brightness to model a single key light.
MaterialMatte. Flat role colours from the palette, no gloss, bloom, glass or reflection. Layers never glow.
LightOne soft key from upper left, one low ambient. A faint contact shadow beneath, nothing else.
CameraPerspective 35° FOV. Orbit limited to ±36° yaw and −8° pitch so the cut is always visible. The back is never shown.
MotionSlow sway, 14 s, ease-in-out, driven only by user attention (hover, focus). At rest it holds a 28° view. Reduced motion holds that view.
STATES · SAME OBJECT, THREE READINGS
IdleHostile stem neutral grey. Spine and bar Verdigris. No node proof.
ThreatUpper hostile segment Ember, lower segment still neutral: at risk, not reached.
ContainedUpper segment Ember, lower held at 35%, node hole sealed with Verdigris.
WHERE IT LIVES

Once per surface: loading and empty states, the response summary, the proof receipt. Never as a background, never repeated in a grid.

BUILD NOTE

Real-time target: extrude the SVG paths, 22 instances, flat shading, no post-processing. The stage on the left is the reference at 1x.
