TYPES · THE MOCK-DATA CONTRACT
type Evidence = { id: 'EV-01'..'EV-07'; source: string; ts: string; summary: string }
type Hop = { node: string; status: 'observed' | 'forecast';
             evidence?: string[]; likelihood?: number }
type AttackPath = { id: 'P1'..'P6'; hops: Hop[];
                    target: 'fin-ledger-db'; likelihood: number; rollouts: 6000 }
type Action = {
  id: 'A1' | 'A2' | 'A3'; kind: 'revoke_grant' | 'kill_sessions' | 'step_up'
  targets: string[]; blocks: string[]            // path ids
  impact: { users: number; processes: number }   // counts, no scores
  rollback: { id: string; seconds: number; method: string }
  authorisation: { policy: string; approvers: string[] } }
type Envelope = { actions: string[]; blocks: 6; minimal: true;
                  subsetsChecked: 4096; certificate: string }
type Claim = { id: string; text: string; method: string;
               evidence: string[]; status: 'verified' | 'failed' | 'stale' }
type Proof = { seal: string; snapshot: string; claims: Claim[]; validUntil: string }
type GateState = 'review' | 'executing' | 'applied' | 'rolled'

ACCESSIBILITY
  • Observed and forecast differ by dash pattern and node ring, not by colour alone.
  • Every graph has a text equivalent: the six-path table on HALT-R1 and the evidence chain on ThreadGraph.
  • Each graph state carries an aria summary, for example “after containment: hostile paths cut, business thread continuing”.
  • All buttons are real buttons, 44 px high, with a 2 px Bone focus ring offset by 2 px.
  • Reduced motion removes the march, pulse and break animation and shows the end state.
  • Secondary text on Ink is at least 7:1. Ember and Verdigris never carry text on Bone.
