SVG RULES
  • Paths only. No text, strokes, filters, masks, gradients or embedded images.
  • One fill per file. The node's hole is a reverse-wound subpath, so the default nonzero rule renders it.
  • Inline UI uses fill="currentColor", so the mark follows text colour.
  • Each file carries role="img" and a <title>. Decorative uses add aria-hidden.
  • Coordinates stay on the 96 grid, one decimal at most.
