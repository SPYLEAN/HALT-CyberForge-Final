A1 — PRODUCT FOUNDATIONS

One visual language: threads

Observed is solid. Forecast is dotted. Business is a thick unbroken thread. Proof is a ring. No line carries meaning by colour alone.
THREAD SEMANTICS

Observed hostile

Solid Ember, 3 px, with an evidence marker. Every solid hostile segment links to a telemetry event.

Forecast hostile

Dotted Ember, 2 px, ending in a dashed ring. Never solid. Slow march motion. No evidence ID, only a simulated likelihood.

Business thread

Thick Verdigris, 8 px, always continuous. A pulse travels it. If it breaks, that is the harm being measured.

Proof signal

Bone ring with a Verdigris centre, set into a gap of 0.22x. Used only where a claim was checked.

Held

Ember at 30%. The downstream part of a path that can no longer be reached. Stays visible so the cut can be audited.
